# 📰 AI Fake News Detection & Content Analysis

An AI-powered misinformation detection and content analysis system built using Natural Language Processing and Generative AI techniques. The project uses transformer-based deep learning models to analyze news content, detect fake news, and demonstrate AI-generated text generation for research and educational purposes.

---

## ✨ Features

- 🧠 Fake news detection using BERT
- ✍️ Synthetic news text generation for research and educational purposes using GPT-2
- 📊 Confidence score prediction
- 🖥️ Interactive Gradio user interface
- 📄 Downloadable analysis reports
- ⚡ Real-time text processing

---

## 🛠️ Tech Stack

- Python
- Hugging Face Transformers
- BERT
- GPT-2
- PyTorch
- Gradio
- FPDF
